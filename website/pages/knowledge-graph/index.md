## How to explore

Start with **Agentic AI & governance**, **Kubernetes lifecycle**, **Security & trust**, or another guided topic. Search for an ADR, component or issue key; use the filters to narrow the graph. Select a node to inspect its relationships and open its original source. Switch from the illustrative Brain mode to Structure mode to explore the force-directed graph.

## What this graph represents

This is a derived projection of the public OpenKubes Git repository, not a live cluster inventory or a certified semantic ontology. Edges reflect text-based extraction; they do not establish runtime dependencies, authorization, or proof of implementation. The public view deliberately excludes commit messages and cluster-state nodes pending a dedicated publication review. Jira keys are references, not imported Jira records.

The graph is rebuilt from Git during the website build. Its source remains the [OpenKubes repository](https://github.com/openkubes/openkubes), not the visualization. 

## The Immortal Mind

Knowledge should be as durable as infrastructure. This explorer makes the documented relationships in our engineering memory accessible to people.

Read [The Immortal Mind manifesto](../openkubes-ai-immortal-mind-manifesto.md) and [If We Built Kubernetes Today](../if-we-built-kubernetes-today.md) for the vision behind this work. The graph does not grant agents operational authority.
