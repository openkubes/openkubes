# GO-1 v1 historical public summary

> **Classification: PUBLIC SANITIZED DERIVATIVE — NOT ORIGINAL EVIDENCE**

This directory summarizes an early, blocked GO-1 protocol draft and its technical
analysis. It is intended for architectural history only.

These files are not the original artifacts, do not preserve the original byte
identity, and must not be used as authorization, execution input, audit evidence,
or a restoration source. The unchanged originals are retained separately under
restricted access.

## Historical outcome

The draft explored one bounded experiment: create one disposable cluster, allow
reviewed existing mechanisms to converge, observe the result, and retain evidence.
It remained blocked and did not grant GO-1 or failure-injection authority.

The analysis identified four main gaps:

1. the semantic contract was not fully projected into an exact reviewed lifecycle
   object set;
2. worker topology and other material renderer inputs were incomplete;
3. the enablement mechanism was not installed and proven with immutable source
   identity; and
4. GitOps placement, target registration, and credential lifecycle were not yet
   selected and evidenced.

Later tracked protocol versions and bounded-runner packages superseded this draft.
They remain separate identities; this summary does not reinterpret them or the
restricted original.

## Sanitization boundary

The public derivative intentionally excludes:

- internal endpoints, address ranges, and environment-specific topology;
- credential, certificate, CA, and identity fingerprints;
- local or private filesystem paths;
- private evidence identifiers and raw evidence locations;
- operational grants, grant identifiers, and execution windows; and
- checksums that could be mistaken for the identity of the original evidence.

See `provenance-and-sanitization.md` before citing or reusing this material.
